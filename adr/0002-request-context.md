# 2. Ресурси і контекст запиту

Статус — запропоновано.

Пул створює точка входу й перевіряє доступність БД. Репозиторій отримує пул один раз, сервіси отримують репозиторій та годинник. Для ініціатора й business-process ID використовується AsyncLocalStorage з одним кореневим HTTP-контекстом. Спільний логер читає його в момент запису, включно з початком і результатом SQL та межами транзакції. Варіант із передаванням об'єкта контексту кожному виклику зробив би всі сигнатури залежними від HTTP-процесу. Неявний контекст потрібно створювати на кожній зовнішній точці входу. Записи самого процесу за межами запиту контексту не мають.
