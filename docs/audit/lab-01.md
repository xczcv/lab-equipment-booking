# Аудит ЛР1

Коментарі в цьому файлі підготував OpenAI Codex 24.11.2026 під час [P02](../../ai/P02.md#p02-audit). Історичних коментарів студента чи рев’юера щодо цих пунктів у доступних матеріалах немає.

## A01-1. Прохід і блокування коміту

**Спостереження.** У локальній початковій ревізії `8b3db1c` команда `git ls-tree -r --name-only main` показала один README. Перша виконувана перевірка з’явилася в `7ed3a2a`. [P01 · етапи](../../ai/P01.md#p01-stages) · [P01 · негативний тест](../../ai/P01.md#p01-lr1-lr4)

**Коментар і критерій.** Потрібні два різні результати на чистих даних. На зрізі ЛР1 `npm ci && make check` має пройти з одним HTTP smoke. Тестовий `git commit -m "test: deliberate hook failure"` має дати код 1 і залишити HEAD на попередньому SHA. Обидва результати є. [Чиста збірка](../../evidence/lab01-clean-check.txt) · [Відхилений коміт](../../evidence/lab01-hook.txt)

## A01-2. Зона дії pre-push

**Спостереження.** `pre-push` викликає `npm run check` для активного checkout. Локальний запуск hook із SHA неформатованого коміту на stdin пройшов із кодом 0, бо checkout уже містив виправлення. Скрипт hook однаковий між `lab-01` і `lab-05`. [P01 · мінімальна архітектура](../../ai/P01.md#p01-stages) · [Команди і вивід](../../evidence/lab01-pre-push-scope.txt)

**Коментар і критерій.** Якщо перед публікацією явно вибрано інший ref, `make check` слід виконати на його чистому checkout. Автоматичну перевірку всіх ref у hook не реалізовано. Критерій зафіксовано в `24932a1`. [Специфікація](../specs/lab-01.md)

## A01-3. Живий процес і готовність даних

**Спостереження.** Smoke у `7ed3a2a` отримав HTTP 200 і `{"status":"ok"}` від зібраного HTTP-сервера. На пізнішому образі `d8afd93` `/health` працював, коли `/ready` ще давав 503. [P01 · межі етапів](../../ai/P01.md#p01-stages) · [P01 · готовність](../../ai/P01.md#p01-lr4)

**Коментар і критерій.** `make check` підтверджує доступність HTTP. Для допуску трафіку у ЛР4 потрібен окремий `/ready` з доступною БД і валідними індексами. Реалізація `d8afd93` пройшла `make container-check` із переходом 503 → 200. [ЛР1](../../evidence/lab01-clean-check.txt) · [ЛР4](../../evidence/lab04-container.txt)
