# ЛР3. Тести життєвого циклу

**Статус — чернетка для погодження студентом.**

Мета — перевірити правила доступності, транзакційну конкуренцію і шлях клієнта через зібраний API.

## Критерії приймання

- На `lab-03` `make test` проходить на ізольованій PostgreSQL. Unit-тести перевіряють відсутній, минулий, граничний, майбутній вільний і майбутній зайнятий слот.
- Інтеграційний тест бачить дві незалежні SQL-сесії, які чекають на той самий слот. Після зняття блокування отримано `201` і `409` та один активний запис. Прямий конфліктний INSERT дає `23505`.
- E2E через HTTP перевіряє пошук, створення, повтор, заборону скасування чужої броні, скасування власної та нове бронювання. Окремий інтеграційний тест перевіряє обидві півночі 23-годинної доби Europe/Kyiv.
- `make mutation` має звіт із кількістю й класифікацією вижилих. Для збережених прогонів один модуль правила доступності дає 8/13 до додавання випадків і 13/13 після.
