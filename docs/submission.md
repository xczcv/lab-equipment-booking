## Що студент готує для DEFENSE

Для кожної роботи студент сам заповнює до однієї сторінки й додає посилання на відповідний PR:

1. Мета роботи в одному чи двох реченнях.
2. Три основні розбіжності або зрізані кути, що змінилося та в якому коміті. Для відкритого обмеження вказати його стан.
3. Власне обґрунтування рішення та альтернатив із ADR.
4. Команда, фактичний результат і SHA перевіреної ревізії. Для ЛР4–ЛР5 додати SHA з `/version` і вказати середовище виміру або розгортання.

Студент погоджує критерії та інженерні рішення. Авторство робочої реалізації й допомогу OpenAI Codex відображено в комітах і записах запитів. Повний матеріал Definition of Done очікується від викладача. [Слід AI](../ai/README.md) · [Накопичувальна специфікація](../spec.md)
